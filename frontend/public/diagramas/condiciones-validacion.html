MotoCore · validación del aislamiento

Cuatro condiciones para demostrar que el aislamiento no se puede apagar

El sistema separa los datos de cada organización con dos controles independientes: uno en la base de datos y otro en el servidor. Estas cuatro condiciones apagan uno, el otro, o los dos — y comparan lo que ocurre.

Qué se quiere probar: que la separación no depende del código del servidor. Si alguien desactivara ese control —por error o a propósito—, la base de datos seguiría entregando cero filas ajenas. La línea base existe para lo contrario: enseñar la fuga cuando no hay reglas en la base, que es como resuelve el aislamiento el software relevado en el mercado.
